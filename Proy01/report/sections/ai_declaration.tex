\section{Declaración de Uso Responsable de IA}
    El código presentado para la realización de este proyecto 
    fue implementado y escrito de forma manual, es decir, sin 
    intervención de IA y únicamente empleando los pseudocódigos 
    y formulas matemáticas presentes en las diapositivas. 
    En cambio, se empleó de la IA, explícitamente el modelo 
    Gemini 3.8 Flash de Google \parencite{google_gemini_3_8_flash}, 
    para resolver consultas referentes a documentación 
    de algunas funciones y métodos (cómo se llaman, qué parámetros 
    reciben, valores especiales) de OpenCV como al momento de leer 
    las imágenes (qué parámetros aceptaba) o para convertir una 
    imagen a escala de gris (consultar el nombre de la función); para 
    estos casos, la verificación fue inmediata, pues al escribir las 
    funciones o parámetros el mismo IDE (VS Code) los sugería.
