\section{Declaración de Uso Responsable de IA}
    Se empleó de IA únicamente para comprender de mejor manera 
    cómo está implementado el algoritmo de Canny en CV2, así 
    como para entender qué argumentos admiten algunas de las 
    funciones de CV2 que se emplearon para obtener las derivadas 
    direccionales de las diferentes imágenes. Específicamente, 
    se usó el modelo Gemini 3.8 Flash de Google \parencite{google_gemini_3_8_flash}.
