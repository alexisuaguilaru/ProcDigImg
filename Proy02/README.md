## Planteamiento del Problema
Se construirá un sistema capaz de detectar estructuras relevantes de una imagen (bordes) empleando diferentes detectores. El pueda emplear los filtros y kernels:
* Prewitt
* Sobel
* Laplaciano
* Laplaciano de la gaussiana (Sombrero mexicano)
* Canny

Donde al menos Sobel y Prewitt deberán implementarse manualmente ocn NumPy sin utilizar funciones de alto nivel que haga un procesamiento equivalente.

## Uso y Ejecución
### Proyecto en Jupyter Notebook
En el caso de estar empleando uv, basta con ejecutar el siguiente comando para abrir y ejecutar la notebook en Jupyter:
```bash
uv run jupyter notebook proyecto.ipynb
```
En caso de estar en un ambiente virtual basado en conda, emplee:
```bash
jupyter notebook proyecto.ipynb
```
